# about-jose

A one-page About Me site for Jose R. (Podoi Tech LLC), styled after [joserod.space](https://joserod.space/).

It is a single static file, `index.html`, with no build step. Open it in a browser or serve the folder with any static host:

```sh
python3 -m http.server 8000
```

## Owner content still to add

- **Contact links**: only joserod.space is listed. Add email, GitHub or LinkedIn in the `#contact` section; a commented template sits above it.
- **Location and interests**: there is a placeholder comment at the end of the bio.
- **Photo**: the page uses a gradient "JR" monogram. Replace the `.monogram` element with an `<img>` to use a photo.
